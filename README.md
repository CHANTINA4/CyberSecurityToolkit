## ✅ Day 1 – Project Setup & IPv4 Basics

### Topics Covered
- Project Setup
- IPv4 Basics
- IPv4 Address Format (`x.x.x.x`)
- Octets
- Octet Range (`0–255`)
- Valid vs Invalid IPv4 Addresses
- User Input in Python

### What I Learned
- Every device connected to a network has an IP address.
- An IPv4 address consists of four octets separated by three dots.
- Each octet must contain a value between **0 and 255**.
- An IP address is considered invalid if:
  - It does not contain exactly **4 octets**.
  - Any octet is outside the range **0–255**.
  - Any octet contains non-numeric characters.
